## 7. 明确的限制（不当作已完成）

1. **Canvas 无任何实测**：无账号 → 全部 ⬜。
2. **AI 未联网联调**：无 API Key → 流式回答标 🟡。
3. **Android 未在设备上运行**：无 AVD 系统镜像/真机 → APK 标 🟡。
4. **扫描件无 OCR**：只标记「需要视觉识别」并保留原图，不假装读懂。
5. **PDF 解析为自研精简实现**：多线、加密、特殊 CID 字体可能退化；无文本时明确提示。
   （已用真实 LaTeX 中英文 PDF 验证分页与 CJK 提取。）
6. **ICS 重复日程**：往返保留 `RRULE` 文本，但日历视图按单次日程展开，不实现完整重复规则。
7. **前端 UI 单元测试**：仅覆盖工具函数与中英文案一致性（13 个），未做完整交互测试。
8. **Canvas 文件正文**：见第 5 节，按设计不支持自动下载。
9. **Android 构建环境限制**：本机无 Developer Mode，无法创建符号链接，改用
   `scripts/build-android.ps1` 复制 `.so`；Gradle 需要经代理访问 `dl.google.com`。

| 登录 Canvas 后软件内不显示登录状态 | 登录发生在独立窗口中，主窗口没有任何信号，必须手动点「检查连接」 | 打开登录窗口时启动后台监视器：检测到已登录的 Canvas 页面就自动执行一次校验并把结果推给主窗口（`canvas://connection` 事件），同时界面在 `logging-in` 状态每 5 秒轮询兜底 |

### 2026-10-18 — 引用卡片显示 S0、正文 [S1] 不可点击

### 2026-10-18 — PDF 页面比例被拉伸 / 第二份 PDF 直接渲染失败

| 问题 | 原因 | 处理 |
| --- | --- | --- |
| 阅读 PDF 时页面比例被强行拉伸 | canvas 同时写死了**像素高宽**，又用 `max-w-full` 让宽度跟随容器收缩——宽度被压小、高度不变，比例就变形了（16:9 的课件被压成接近方形） | 用 `ResizeObserver` 量出可用宽度，按**同一个缩放系数**同时计算宽与高；backing store 仍按 devicePixelRatio 全分辨率渲染，缩放只影响显示 |
| 打开另一份 PDF（A4 纵向）直接显示「无法渲染 PDF」 | pdf.js 不允许同一 canvas 并发渲染：页面/缩放/尺寸变化会启动新的渲染，而上一帧还没画完 | 渲染串行化（一条 promise 链），并在切换时 `cancel()` 上一帧；取消异常不再当作错误上报 |

**实测（真实课件，读取 canvas 的渲染尺寸）**：

| 课件 | 源比例 | 修复后渲染比例 |
| --- | --- | --- |
| U2L1 Academic Discussions（16:9，1440×810） | 1.7778 | 1.7788（窗口 1280px）/ 1.7778（窗口 600px） |
| classwork1-2（A4 纵向，595×842） | 0.7071 | 0.7072 |

窗口从 1280px 缩到 600px 的整个过程没有再出现渲染错误，比例始终等于源文件比例。
### 2026-10-18 — 放大超过窗口后再也放不大

| 问题 | 原因 | 处理 |
| --- | --- | --- |
| PDF 放大到超过窗口宽度后就无法继续放大 | 上一版为了修复拉伸引入了 `fit = min(1, frameWidth / 页面宽度)`，把显示宽度**永远钉在容器宽度**：页面越放大，fit 越小，视觉尺寸恒定，缩放等于失效 | 缩放改为相对面板宽度：100% = 适应宽度，超过 100% 即溢出；页面放进可滚动容器，并可按住鼠标拖动平移；「适应宽度」按钮放在**左侧翻页区**，缩放不为 100% 时出现，且不会推动右侧「− / % / +」的位置（实测 100% 与 175% 下两个按钮的 x 坐标完全一致：883 / 965） |

**实测（真实课件，读取 canvas 与容器的实际尺寸）**：

| 缩放 | 画布 CSS 尺寸 | 容器宽度 / 内容宽度 | 比例 | 可横向滚动 |
| --- | --- | --- | --- | --- |
| 100%（适应宽度） | 756×425 | 746 / 746 | 1.7788 | 否 |
| 175% | 1323×744 | 746 / 1331 | 1.7782 | 是，拖动后 scrollLeft = 120 |
| 400%（上限） | 3024×1701 | 746 / 3032 | 1.7778 | 是，拖动后 scrollLeft = 300 |

backing store 上限 1600 万像素（400% 时正好触顶），避免超高缩放下分配过大的 canvas；比例始终保持源文件比例，无渲染错误。
迁移：`002_citation_page_kind.sql`（`ALTER TABLE chat_citations ADD COLUMN page_kind`）。

## 9. 状态定义

- **✅ 已支持**：在本机真实运行并得到有效数据（或合法空结果），可复现。
- **🟡 已实现·待实测**：代码完整、自动化测试通过，但缺少真实外部输入（账号/密钥/设备），
  尚未完成端到端验证。
- **⛔ 按设计不支持**：出于安全约束或平台能力明确不实现，产品内提供替代路径与说明。
- **⬜ 未测试**：尚未验证，且当前环境无法验证。

任何能力的降级都会同步反映到界面上（能力表、索引状态、引用来源标注），
不会出现「界面说支持、实际没有」的情况。
